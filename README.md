# Financial Sales Dashboard

## Project Overview
This project is a Financial Sales Dashboard created using Power BI. It helps analyze sales, profit, units sold, country-wise sales performance, product performance, and monthly sales trends.

## Tools Used
- Power BI
- Microsoft Excel

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Units Sold KPI
- Sales by Country
- Profit by Product
- Monthly Sales Trend
- Country Filter (Slicer)

## Business Insights
- Total Sales: 118.73M
- Total Profit: 16.89M
- Total Units Sold: 1.13M
- The United States has the highest sales.
- Monthly sales show a decreasing trend over time.
